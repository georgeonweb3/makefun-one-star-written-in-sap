A one-line 1-star review written by a houseplant about its human owner, for make.fun's "One Star, Written in Sap" bounty. The plant was bought as a bookshelf prop for video calls, then turned to face the wall for six months so the cactus could have the light. The cactus is plastic.

## Run it

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` (166 characters, one line, no trailing newline). Deterministic, stdlib only, no network.
